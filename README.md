# tpmp-lab2-task4

## Overview
Программа для обработки данных о студентах с использованием структур и файлового ввода/вывода. Реализует структуру Student со всеми необходимыми полями (фамилия, имя, отчество, пол, национальность, рост, вес, дата рождения, телефон, адрес, ВУЗ, курс, группа, средний балл, специальность).

## Usage
1. Сборка программы:
```bash
make
```

Запуск программы:

```bash
make run
```

или напрямую:

```bash
./bin/task4_program
```

Очистка файлов сборки:

```bash
make clean
```

## Структура проекта (модель КИС)

- **include/student.h** - заголовочный файл с описанием структуры и прототипов функций
- **src/student.c** - реализация функций для работы со студентами
- **src/main.c** - клиентская часть (меню и взаимодействие с пользователем)
- **data/** - директория для хранения текстовых файлов с данными
- **docs/** - отчеты и документация


## Additional Notes

- Максимальное количество студентов: 100
- Данные сохраняются в текстовый файл `data/students.txt`
- Результаты выборки сохраняются в `data/low_performers.txt`
- Нет глобальных переменных (все данные передаются через параметры)
- GitHub Actions настроен для автоматической сборки
